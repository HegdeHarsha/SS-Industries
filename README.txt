HOW TO PUBLISH
1. Create a GitHub repo, upload ALL files in this folder (keep the assets/ folder).
2. Repo Settings > Pages > Deploy from branch > main > / (root). Save.

HOW TO EDIT (config.js)
- Add a product: copy a block in products[] and change the text.
- Hide a product: set visible: false.
- Ladder product: contact: "ladder" (goes to 9742986679), otherwise "main" (8050451188).
- Product photo: put the file in assets/products/ and set image: "assets/products/name.jpg".
- Gallery: set gallery.enabled to true and list images in gallery.images.
